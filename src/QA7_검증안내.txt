GeoField R12.13 QA7 — 보관된 FEA 결과 신뢰성·회귀 검증

QA6 누적 기능 유지. 이번 QA7 변경 내용:
- 보존된 과거 FEA 보고서 수치를 실제 INP/STA/FRD에서 재검증한 결과와 대조
- 응력·변위·메시 수가 일치하지 않으면 저장 값을 조용히 고치지 않고 검증 실패로 처리
- 실행 중/실패/대기 상태의 FEA 작업에서 이전 결과 및 3D 필드 데이터 제거
- 기존 FE 솔버·3D JS·ML 가중치는 바이트 단위로 변경 없음
- 별도 실행 파일을 새로 만들지 않음. 압축 해제 후 기존 GeoField_Start.cmd 사용

개발 환경 근거: 실제 3kg CalculiX 원본(FRD/INP)을 포함한 회귀 테스트 46개 통과,
JavaScript 문법 검사와 14개 배포 파일의 SHA-256 검사 통과.
설치·업데이트·롤백은 테스트 폴더로 모의했으며 실제 Windows 검증은 아직 하지 않음.

제한: 이 파일은 기존 Windows GeoField 런타임(8a9ac53a821a0eb5)용 업데이트 패키지임.
내부에 CAD 엔진, Gmsh, CalculiX와 모든 기존 런타임 모듈을 포함하지 않음.
새 STEP의 실제 3단계 메시 수렴 및 최신 10kg Windows 계산 원본 재검증은 미완료.
Windows 테스트는 최종 누적 통합 패키지에서 한 번에 진행할 예정.
