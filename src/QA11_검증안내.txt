GeoField R12.13 QA11 — 동일 조건 3회 메시 계산 시작 보장 및 런타임 선점검

기준: QA10 누적 업데이트. 기존 SOLVER/FRD/ML 가중치와 사용자 데이터는 변경하지 않음.

수정:
- 3단계 메시 계획 요청 시 확인한 FEA 조건 SHA를 실행 요청 헤더에 실어 보냄.
- 서버는 현재 저장된 FEA 조건 SHA와 대조. 일치하지 않으면 STEP 업로드/메시 계산 전에 HTTP 409로 거절.
- 부트스트랩은 설치 전에 기존 3단계 메시 런타임 파일 5개의 존재 여부를 검사.
- QA10의 HTTP 상태조회 재시도/중단 버튼 복구 코드를 그대로 보존.

제약: 본 ZIP은 기존 GeoField 설치 환경 전용 업데이트. 원본 STEP은 있으나 이 환경에는 CalculiX/Gmsh 실행 파일이 없어 실제 3단계 신규 계산은 아직 실시하지 않았음.
Windows 사용자는 지금 테스트할 필요 없음. 최종 Windows 3단계 수렴 검증은 별도 필요.
