GeoField R12.13 누적 통합 검증 후보 — Windows 1회 확인 체크리스트

기준: QA11 + 세 가지 메시 계산 완료 후 기록 검증 실패의 UI 상태 차단 개선.
개발 환경: pytest 96 통과, JS 문법 통과, 배포 14개 payload SHA 검증.
주: Windows 실제 WebGL · Gmsh/CalculiX 3회 신규 계산 · ML 런타임은 이 환경에서 종단 간 미검증.

설치/실행 (기존 GeoField Runtime 사용):
1. 진행 중인 FEA/ML/STEP 작업을 종료하고 작업 저장. 기존 서버가 8600을 점유하면 실행기가 GeoField 소유 여부를 확인해 해당 서버만 자동 정리 시도. 불확실하면 설치 중단.
2. ZIP 압축 전체를 해제하여 GeoField_Start.cmd 실행 (ZIP 내부에서 CMD 실행하지 말 것).
3. 설치 전 원본 무결성 확인, 기존 파일 백업 및 불일치 차단. 기존 데이터 삭제하지 않음.
4. http://127.0.0.1:8600 에서 현재 STEP 불러오기, CAD 측정값 확인.
5. 실제 FEA 재료/고정/하중/방향 확인 후 저장, 한 번의 CalculiX 계산, 3D 응력·변위 및 보고서 값 교차 확인.
6. 기존 FEA 이력 복원, CAD 교체 시 잘못된 이력·모델 연결 차단 확인.
7. 3단계 메시 계획을 승인하고 3회 실제 계산을 실행 (시간/CPU 부하 유의).
8. 3개 실제 실행 ID 및 INP/STA/FRD, 메시별 응력/변위/최고 응력 위치, 하중 모멘트 비교를 확인.
9. 수렴 '인증'이 아니라 수치 안정성 진단인지 확인. 계산 중단/FRD 누락 시 연구를 완료로 표시하지 않아야 함.
10. R12 연구용 ML은 FEA와 별도 분석으로 표시되는지 확인.

실제 Windows에서 오류 시 전달 정보: CMD 화면, diagnostics 로그, 브라우저 오류 화면 (개인정보/토큰 제외).
CalculiX 계산 파일을 이 ZIP 안에 새로 생성하거나 과거 계산값으로 대체하지 않음.
