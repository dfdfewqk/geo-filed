## 검증 대상과 절대 구분

Windows 녹화에서 확인된 `SUS304`, `10 kg` 질량 환산 하중 및 `+X` 방향을 **기존 공개 STEP L-bracket**에 적용한 별도 실측 계산이다. Windows 녹화의 고정 면 3/하중 면 1은 FreeCAD 뷰어 면 ID이므로 Gmsh 공개 모델의 면 ID와 같다고 가정하지 않는다. 이 시험은 Gmsh에서 실측 면 중심 `(0,0,25)` mm와 `(25,0,0)` mm을 선택했으며 결과적으로 **Gmsh 고정 면 1, 하중 면 3**이 사용됐다. **사용자의 원본 프로젝트/고정면/하중면 재계산이 아니다.** 영상에서 확인된 26.410 MPa, 0.04477 mm와 수치가 다른 것은 당연하며 이 시험 수치로 대체하지 않는다.

- Public original SHA-256: `fe65841074c5fc6bd74442b147e5688490ec1ad79d5fb1e41bdccd3514bccf32`.
- E=193000 MPa, ν=.29 (SUS304 대표 참고 물성), 외부 힘 **98.0665 N** (10 kg × 9.80665), 방향 +X, 자중 OFF.
- 실제 Gmsh 생성 C3D4 또는 직선 C3D10 + `straight_tri6_full_consistent`; INP → CalculiX 실제 계산 → STA/DAT/FRD·분산력·반력·3D 필드 검증. **가짜 수치 없음.**

## 실제 코드에 반영한 변경

1. **새 브라우저 FEA 계산에만** `c3d10_full` + `fine` 메시 기본 선택. 전체 면하중과 고정 공유 절점 직접 하중의 반력을 별도 분리·검증하는 기존 실제 계산 코드 사용. 추가 단추 없음.
2. `resetModel()`은 새 STEP 불러올 때만 `c3d10_full`, `fine`, 자중 OFF로 복귀한다. 과거 계산 `resetModel({preserveRestore:true})` 시 **원래 C3D4/C3D10 요소·자중 저장조건을 보존**.
3. 기존 REST API와 저장된 C3D4 데이터는 기존 기본 C3D4·서명 규칙 유지. 자중+전체 Tri6 조합은 현 단계에서 차단하며 자동으로 물리조건을 바꾸지 않는다.
4. 자동 회귀 테스트는 HTML 기본 선택·새 STEP/기록 복원 구분·기존 케이스 SHA 일치 및 Windows 패키지의 정확한 UI 파일 존재 여부까지 검사한다.

**한계:** 임의 CAD, 다른 면쌍, 자중/비선형, 진동/피로 등은 별도의 검증이 필요하며 이 성공 결과를 사용자 다른 경우의 안전성으로 확장하면 안 된다. Windows 실제 원본 CAD + 기록 + 3D 재시작 복원 검증은 최종 통합 테스트 때 한 번 수행한다.
