# GeoField — 3번 원클릭 자동화 통합 조정 (2026-11-05)

기준: `work/geofield-step3-oneclick-pipeline-coordinator-20261105` · 원본 L-브래킷 STEP 한 건. 기존 STEP, SQLite 이력, 모델 가중치, 실제 CalculiX 산출물, UI·기존 기능은 보존한다. 사용자 Windows PC 실사용 검증은 **개발·자동검사를 모두 마친 맨 마지막**에 시행한다.

## 한 번의 '결과 분석' 버튼이 의미하는 것

- 전제: STEP 파일을 이미 선택·등록했고 고정 면, 하중 면, 재료, 물리적 하중·방향을 설정한 상태. 불명확한 물성/힘을 임의로 채우거나 누락을 추정하지 않는다.
- ① 설정 미저장 시 동일 버튼에서 조건 준비(검증·예외 동의)를 수행. 준비가 거절되거나 STEP·입력 선택이 바뀌면 실제 솔버 POST는 하지 않는다.
- ② 현재 CAD SHA, 서명된 물리 조건 SHA를 기준으로 **단일 실제 CalculiX 기본 FEA를 한 번만** 요청한다. 작업 ID, 원본 INP/STA/FRD·수치 검증, 3D 필드 수신 및 SQLite 읽기용 연결을 유지한다.
- ③ 동일 실행 ID의 독립 검증 요약이 늦게 도착하면 **같은 실행의 결과 조회만 최대 8회** 재시도한다. 다음 단계로 넘어가기 위해 새로운 물리 해석을 중복 실행하지 않는다.
- ④ 신뢰할 수 있는 기본 FEA 실행이 확인되면 기존 로컬 Gmsh/CalculiX **3개 메시 민감도 연구**를 순차 실행한다. 실제 크기·조건·원본 FRD를 별도 재검증하며 수렴·안전을 자동 인증하지 않는다.
- ⑤ 같은 실행의 CAD·FEA·ML/R12 연구 상태·3D·메시 근거로 **로컬 rules-only AI + 통합 HTML 보고서**를 준비한다. 보고서 보기·파일 저장은 사용자가 명시적으로 누를 때만 실행한다. 외부 유료 AI 토글은 기본 OFF이며 자동 과정에서 호출하지 않는다.
- ⑥ 기존 FEA가 자동으로 SQLite에 보존된 것을 동일 run ID로 확인하고, **사용자가 이미 선택한 과거 실행 기록이 있을 때만** 읽기 전용 자동 비교한다. 이전 기록을 자동 변경·삭제하지 않는다.
- ⑦ 완료된 원클릭 흐름 뒤에만 결과 탭의 로컬 AI UI를 갱신한다. BrepMFR/R12가 늦게 끝나면 동일 CAD/동일 FEA run에 한하여 연구 상태 버전을 확인하고 보고서 설명을 **읽기 전용으로 재생성**한다. 계산·유료 API·SQLite 쓰기 없음.

## 이번 수정에서 막은 실질 위험

1. **중복 클릭과 입력 변경:** 자동 조건 저장을 시작하는 순간부터 마지막 메시·보고서·기록 비교가 끝날 때까지 입력 및 원클릭을 잠근다. 후속 작업 도중 별도의 물리 해석을 다시 시작하지 않는다.
2. **응답 유실:** 솔버 POST를 보냈으나 서버 응답이 끊기고 실행 ID가 안 왔다고 계산이 거절된 것은 아니다. 상태는 **실행 여부 불명/재실행 금지**로 두고 기존 서버 로그를 확인하도록 표시한다. 명시적인 HTTP 거절과 구별한다.
3. **연구 결과 시간차:** ML/R12가 결과 보고서 작성 중 또는 작성 후 종료될 수 있다. 보고서의 연구 근거 버전을 추적하고 같은 실행의 보고서만 최대 3번 읽기 전용으로 다시 확인한다. 유료 요청, 자동 팝업, 검증 수치 변경, 임의의 ML 성능점수 생성 금지.
4. **3회 메시 미완료/불확실:** 상태 종료가 확정되지 않은 경우 자동 결과 전환이나 새 계산을 진행하지 않고 입력 잠금을 유지한다. 기존 완료된 단일 FEA는 보존한다.

## 자동 검증 범위 / 운영상 구분

- 새 회귀: 준비 실패 시 0 FEA POST, 한 클릭의 1 POST→메시→HTML→기록, 결과 생성 중 두 번째 클릭 0 POST, 응답 유실 잠금, 명시적인 거절, 늦은 SQLite 검증 조회.
- 새 회귀: 늦은 ML 완료 후 동일 FEA 보고서 갱신, 중복 갱신 coalesce, 진행 중 갱신 차단, STEP SHA 변경 시 기존 보고서 차단, 자동 유료 AI 0 요청.
- 전체 GitHub Actions: JS/웹 회귀, Ubuntu·Windows 보고서, 기존 실제 솔버 CI fixture, Windows Python 3.13 배포 및 기존 설치 호환성.
- **실제 사용자 Windows 원본 L-브래킷 통합 동작은 이 자동검사로 완료라고 주장하지 않는다.** 자동검사가 모두 통과해도 마지막 한 번의 사용자 PC에서의 종단 간 검증만 남는다.
- CAD 홀·필렛에 대한 응력 집중 인과성, 소재 항복강도·설계 안전율, 3회 메시의 확정 수렴, 독립 ML 정확도는 별도 증거 없이는 미검증으로 유지한다.

본 작업은 feature 브랜치에서 수행하며 `main` 직접 수정·조기 EXE/ZIP 제공·Windows 반복 수동 테스트 요청을 하지 않는다.
