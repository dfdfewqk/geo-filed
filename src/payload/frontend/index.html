현재 CAD 분석 결과

기록의 기존 보고서는 과거 CAD 형상 측정 자료입니다. 위 통합 보고서는 현재 실행한 ML과 FEA의 상태도 구분해 보여줍니다.

실제 CAD 기하학적 치수

STEPFeatureNet의 기하학적 치수 계산 원리를 CAD B-Rep에 적용합니다. 학습 가중치는 사용하지 않으며, ML 형상 분류·관통 여부·안전성은 판정하지 않습니다.
STEP을 불러온 뒤 확인하세요.

GeoField 근거 분석 에이전트

에이전트 연결 확인 전 · 외부 LLM 연결 확인되지 않음. 근거 검증을 실행해 상태를 확인하세요.
동의한 경우에만 CAD 후보 개수와 검증된 FEA 최대 응력·변위 등 최소 요약을 외부 API로 보냅니다. STEP·FRD 파일, 파일명, 실행 ID와 SHA는 전송하지 않습니다. API 키는 인증을 위해 제공업체에만 전달하며, 모델 입력과 저장 기록에는 넣지 않습니다. 외부 모델 설명은 계산 근거가 아닙니다.
CAD를 불러온 후 검증된 분석 결과를 요청하세요. 이전 결과를 현재 CAD와 혼합하지 않습니다.
ML은 연구용 참고 자료입니다. FEA 응력·변위는 실제 원본 계산 재검증이 통과한 경우에만 표시합니다. 구조 안전성은 보증하지 않습니다.
