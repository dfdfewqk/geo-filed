# GeoField — C3D10 하중·고정면 공유 절점 보정 (실측 / 개발 분기)

날짜: 2026-10-26. 이 작업은 기존 C3D4·C3D10 기본값을 바꾸지 않는다. 메인 브랜치와 PR #4의 물리 계산은 그대로 유지한다.

## 원인과 이번 수정

기존 선택형 C3D10 구현은 직선 6절점 삼각형(Tri6)의 이론적인 일정 벡터 면하중(A/3씩 각 중간 절점)을 계산하지만, 선택한 하중면과 고정면의 공유 절점을 제외하고 나머지 절점으로 힘과 모멘트를 재분배했다. 이 때문에 전체 하중·모멘트가 같아도 각 지점의 하중과 응력은 달라진다.

이번 분기에만 실험 옵션 `case["mesh_request"]["traction_model"]="straight_tri6_full_consistent"`를 추가했다.

- **기존 기본값**: `free_node_moment_equivalent`. 원래의 공유 고정 절점 제외 및 힘·모멘트 보정 방식 보존.
- **새 선택값**: C3D10의 직선 삼각형 각 면 중간 절점의 일관된 하중(A/3)을 모두 사용. 고정면과 공유되는 중간 절점의 `*CLOAD`도 INP에 기록. 전체 힘·모멘트와 원본 INP 작성 내용을 별도 검증.
- CalculiX의 `*NODE PRINT RF` 출력은 직접 고정 절점 CLOAD가 있을 때 그 외력을 포함하지 않는 것으로 **실제 계산으로 확인**. 물리적 지지 반력 = 인쇄된 RF − 고정 절점의 직접 CLOAD. 이 보정 후 전체 `F + R = 0`, 전체 `M + M_R = 0` 확인. 생 RF와 적용 고정점 외력의 별도 증거 보존.
- C3D4, 기본 C3D10, 혼합 요소 및 기존 `INP/STA/FRD/SQLite`는 변경하지 않는다. 자중(GRAV)과 새 선택값의 동시 사용은 검증되지 않았으므로 차단한다.
- 형상은 아직 **직선 모서리 C3D10**. CAD 곡면 재현이나 국부 특이점, 응력 안전성을 입증하지 않는다.

## 실제 Gmsh + CalculiX A/B 계산

동일한 공개 `fixtures/L_bracket.step` (SHA-256 `fe65841074c5fc6bd74442b147e5688490ec1ad79d5fb1e41bdccd3514bccf32`)에서 세 메시 크기별 다음 세 계산을 **실제 독립 실행**했다.

1. 기존 C3D10 생산용 기본 모드
2. 원본 INP의 노드와 요소 순서를 전부 대조한 후 `*CLOAD` 카드만 교체한 독립 실험용 CCX 입력
3. 새 선택 기능을 활성화한 **생산용 fea_solver.py** 실행

3번의 INP SHA-256, 응력/변위가 같은 크기의 2번과 정확하게 일치하는지 테스트했다. 모든 단계에서 실제 solver로 STA/FRD/DAT 생성 후 재읽기, 3D 표면 필드 생성까지 검증했다.

| Gmsh 대상 (mm) | 기존 C3D10 최대 응력 (MPa) | 새 선택값 최대 응력 (MPa) | 기존 최대 변위 (mm) | 새 선택값 최대 변위 (mm) |
| ---: | ---: | ---: | ---: | ---: |
| 3.00 | 20.724668 | 20.773404 | 0.087864 | 0.088198 |
| 2.25 | 21.287545 | 21.321629 | 0.088807 | 0.089055 |
| 1.70 | 22.162332 | 22.198218 | 0.089894 | 0.090090 |

새 선택값의 기존 모드 대비 변화: 최대 응력 +0.235%/+0.160%/+0.162%, 최대 변위 +0.381%/+0.279%/+0.219%. 이 차이는 하중 정의의 국소적인 차이를 보여줄 뿐, 어느 해석이 구조적으로 안전하다는 주장은 아니다.

### 직접 고정 노드에 가해진 하중 및 평형 실측

| 메시 (mm) | 고정면 공유 CLOAD 노드 수 | 고정 노드 외력 Z (N) | RF에서 외력 보정 후 합력 잔차 (N) | 모멘트 잔차 (N·mm) |
| ---: | ---: | ---: | ---: | ---: |
| 3.00 | 10 | −0.237532 | 0.00000130 | 0.00003134 |
| 2.25 | 14 | −0.176765 | 0.00000418 | 0.00005504 |
| 1.70 | 18 | −0.140078 | 0.00000362 | 0.00004821 |

반력을 **보정하지 않은 채** 전체 CLOAD + 원시 RF로 계산하면 위 고정 노드 외력 크기만큼 힘 잔차가 발생한다. 이 차이를 숨기지 않고 별도 기록했다. 참고: 이 연구는 단일 공공 L-브래킷 기하/하중으로 확인된 동작이다.

## 코드 및 검증

- `src/payload/fea_solver.py`: 명시적 선택일 때만 고정 절점 직접 CLOAD 및 RF 보정 허용. 검증 실패는 계산 성공으로 표시하지 않음

- `src/tests/test_fea_c3d10_shared_traction.py`: 원본 INP 비-CLOAD 항목 변경 차단, 일관된 하중 적분·모멘트 확인
- `src/tests/test_fea_production_c3d10.py`: 기본 경로의 이전 차단 동작과 새 명시적 동작 및 반력 보정 검증
- `.github/workflows/fea-shared-edge-traction-research.yml`: 실제 Ubuntu Gmsh+CalculiX, 원본 출력 아티팩트
