GeoField R12.13 QA3 — 메시 수렴·응력 집중 위치 진단 업데이트

기반 버전: 검증된 QA2 통합 ZIP. 원본 기능과 사용자 데이터 보존.

수정된 런타임 소스: GeoField_CAD_Analysis.py, frontend/cad.js.
1. 실제 3개 메시 결과와 INP/STA/FRD 기록의 재검증을 통과한 경우에만 메시별 응력 집중 위치를 비교합니다.
2. 자중 활성 시 밀도·중력 가속도·방향이 서로 다르면 동일 물리 조건의 메시 비교로 취급하지 않습니다.
3. FRD 표면 절점 최대 응력과 좌표, 메시 간 최고 응력 위치 이동 거리를 표시합니다.
4. 전체 절점 응력 최대값과 표면 절점 최대값은 다를 수 있으므로 구분합니다.
5. 단일 결과의 계산 완료나 5% 기준 충족만으로 메시 수렴 및 구조 안전을 인증하지 않습니다.

독립 검증 근거: 보관된 실제 3kg FEA는 단일 메시 결과이므로 메시 수렴 여부는 판단할 수 없습니다.
메시 위치 비교는 실제 동일 물리 조건에서 다른 메시로 3회 해석한 기록이 있어야 가능합니다.

설치: 기존 GeoField Windows 런타임에 대해서만 기존 GeoField_Start.cmd를 통해 안전 패치합니다.
코드 해시 검사, 기존 버전 호환성 및 롤백 시험 후 최종 실행 검증을 권장합니다.
현재 파일은 향후 최종 통합 검증을 위한 개발 보관본으로서, 지금 설치할 필요 없습니다.
