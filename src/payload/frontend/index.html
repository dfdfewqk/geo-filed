STEP 원본은 변경하지 않고 측정합니다.

파일을 선택하지 않았습니다
STEP/STP · 최대 64 MB · 원본 변경 없음

모델 정보

분석할 CAD가 없습니다.

현재 설정과 다른 과거 계산도 별도 검증 후 읽기 전용으로 복원할 수 있습니다. 새 계산을 실행하거나 현재 저장 설정을 덮어쓰지 않습니다.

조회된 기록은 복원할 때 .inp·.sta·.frd와 3D 필드를 다시 검사합니다.
저장된 실제 FEA 성공 기록을 선택하면 CalculiX 파일을 다시 검증하여 응력·변위를 여기에 표시합니다. 현재 입력 중인 FEA 조건은 변경하지 않습니다.
먼저 실제 계산값의 FRD 검증을 완료하세요. 과거 결과는 오른쪽 3D 화면에 표시되며 현재 CAD/FEA 조건은 변경하지 않습니다.

실제 FEA 메시 3단계 실행 관리

현재 저장된 CAD·재료·경계조건을 유지하며 메시 크기만 굵음/기준/미세로 변경합니다. 승인하면 CalculiX 계산을 최대 3회 순차 실행할 수 있어 시간이 오래 걸립니다. 메시 수렴·안전 승인 아님.

먼저 FEA 조건을 저장하고 메시 계획을 확인하세요.

하중 분포 및 응력 표시 · 실제 계산 근거 확인
실제 CalculiX 계산이 완료되어야 3D 분포를 표시할 수 있습니다.
응력 색상 범위·하중 비교 (고급)
현재 결과의 응력 분포를 자동 범위로 표시합니다. 하중별 색상 비교는 「하중 비교」를 선택하세요.
기본 모드는 실제 FRD 절점 응력으로 높은 응력 위치를 찾습니다. 하중의 크기 차이를 색으로 비교할 때는 「하중 비교」를 선택하세요. 빨강은 선택한 범위에서 높은 응력이며 안전·파손 기준이 아닙니다. 노드 해상도·메시 수렴을 따로 검증해야 합니다.
변형은 시각화 전용입니다. 5배·20배는 계산 결과가 아니라 화면상의 변위 확대입니다. 변형 표시를 해제하면 원래 형상을 볼 수 있습니다.
03 / VERIFIED RESULTS

계산 결과·AI 근거

실제 CAD와 FEA 계산 결과를 먼저 확인합니다. 외부 AI·연구 ML과 구분해 표시합니다.

현재는 규칙 기반 근거 정리만 제공

CAD 치수는 실제 B-Rep 측정값입니다. 연구용 ML은 별도 참고 결과이며 실제 응력 계산이나 구조 안전 판정에 사용하지 않습니다.

① 현재 계산 결과

CAD를 불러오면 측정값·ML·FEA 진행 상태가 표시됩니다.

② 규칙 기반 AI 근거 검토

현재 CAD와 검증된 FEA 실행만 사용합니다. 외부 LLM이나 미연결 학습 모델의 답변이 아닙니다.

에이전트 연결 확인 전 · 외부 LLM 연결 확인되지 않음. 근거 검증을 실행해 상태를 확인하세요.
외부 LLM 설명 요청 (미연결일 수 있음 · 선택)
동의한 경우에만 CAD 후보 개수와 검증된 FEA 최대 응력·변위 등 최소 요약을 외부 API로 보냅니다. STEP·FRD 파일, 파일명, 실행 ID와 SHA는 전송하지 않습니다. API 키는 인증을 위해 제공업체에만 전달하며, 모델 입력과 저장 기록에는 넣지 않습니다. 외부 모델 설명은 계산 근거가 아닙니다.
CAD를 불러온 후 검증된 분석 결과를 요청하세요. 이전 결과를 현재 CAD와 혼합하지 않습니다.
ML은 연구용 참고 자료입니다. FEA 응력·변위는 실제 원본 계산 재검증이 통과한 경우에만 표시합니다. 구조 안전성은 보증하지 않습니다.

BrepMFR 실험적 ML 진단

로컬 모델 실행 환경을 확인하는 중입니다.
ML 진단 미실행. 결과는 설계 판정에 사용되지 않습니다.

R12 홀 분류 · 현재 CAD에서 직접 실행 (연구용)

실제 STEP에서 관통홀·막힌홀 후보를 분석합니다. 모델과 B-Rep 끝면 증거가 일치하는 경우만 후보로 표시합니다. R12 내부 면 참조번호는 기존 3D 선택 면 ID와 연결되지 않습니다. 미검증은 확정하지 않으며 응력·하중·FEA 입력에 반영하지 않습니다.

고응력 위치 검증 후 3D 표시를 선택할 수 있습니다. 기존 CAD 작업은 변하지 않습니다.

기존 FEA 성공 기록을 선택하세요. 새로운 계산을 실행하거나 현재 CAD 설정을 변경하지 않습니다.

고응력 후보 × 주변 사면체 메시 품질

같은 실제 CalculiX 실행의 FRD·INP를 재검증하고 고응력 표면 절점과 하나 이상의 꼭짓점을 공유하는 C3D4 사면체만 품질을 집계합니다. 거리 기반 분석이나 결함·안전 판정이 아닙니다.

기록·비교에서 실제 FEA 성공 기록의 ‘응력·메시 연계’를 선택하세요. 계산은 실행하지 않습니다.

실제 FEA 메시 품질 (C3D4 · 읽기 전용)

성공 기록의 '메시 품질'을 누르면 실제 CalculiX INP/STA/FRD를 재검증한 후 C3D4 사면체 형상 품질을 계산합니다. 새 계산은 하지 않습니다.

실제 계산 완료 기록을 선택하세요. 형상 품질은 메시 수렴·구조 안전성 승인과 별개입니다.

실제 계산 3건의 메시 민감도 연구
