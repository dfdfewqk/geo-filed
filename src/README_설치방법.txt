GeoField R12.13 — 통합 최종 테스트 후보 (2026-10-21)

포함된 작업
  1단계: 선택 면의 하중 노드·총힘·하중 중심·모멘트 오차 검증
  2단계: 계산 전에는 선택 면의 여러 안내 화살표, CalculiX 성공·INP/STA/FRD 검증 후에만 실제 CLOAD 절점 대표 위치 표시(최대 24곳)
  3단계: 메인 WebGL 3D에서 FRD 표면 절점의 실제 von Mises 응력/변위 값을 GPU 보간해 표시. 삼각형 평균으로 고응력 집중 영역을 흐리지 않음
          기본 '응력 분포'는 이번 계산의 최고 응력에 맞춰 색상 조정(위치 찾기),
          '하중 비교'는 같은 STEP의 첫 계산 기준 MPa를 고정(하중 크기 비교), '직접 지정'도 가능.
          기존 과거 계산 2D Canvas 미리보기는 작은 메시에서 유한한 보간 타일을 사용(대형 메시에서는 평균으로 간략 표시).
  실행 코드/기능 보존: 기존 CAD 형상·재료·하중 분배식·Gmsh·CalculiX·ML 가중치·SQLite/INP/STA/FRD 데이터는 수정하지 않음.

설치 방법 (별도 CMD 내려받기 불필요)
  1. GeoField 작업 저장 후 기존 서버 CMD에서 Ctrl+C로 종료. 포트 8600을 다른 프로그램이 쓰면 해당 프로그램의 정상 종료가 필요.
  2. 이 ZIP 파일을 우클릭 → 모두 압축 풀기.
  3. 압축 해제한 폴더의 GeoField_Start.cmd 실행. ZIP 창 안에서 실행하면 필수 파일 경로가 없어 정상 작동하지 않음.
  4. 브라우저 화면 표시 후 Ctrl+F5. 동일 STEP으로 기존 결과 열기 또는 신규 FEA 실행.

테스트 항목
  동일 STEP에 5kg → 15kg: 기본 '응력 분포'에서 두 조건 모두 최고 응력 위치를 구별할 수 있어야 함.
  '하중 비교'에서는 첫 계산의 MPa 기준을 유지해 높은 하중의 색 변화가 나타나야 함.
  고정면·하중면 및 힘 방향 표시와 FRD 최대 응력 위치가 계산 결과에 따라 나타나는지 확인.
  참고: 본 설치기는 기존 Windows GeoField Runtime 폴더가 있어야 함. 처음부터 Windows 전체 패키지를 설치하는 독립 EXE가 아님.
  실제 Windows GPU WebGL, CalculiX 새 계산, Defender 판정은 여기서 수행하지 못해 Windows에서 최종 확인 필요.
  빨간색은 상대적 응력 크기 표현이지 파손이나 구조 안전 판정이 아님. 메시 수렴 별도 검증 필요.

안전: 내부 파일은 별도 소스이며 해시 검사를 통과해야 설치. 어떤 Python 모듈도 외부에서 자동 다운로드하지 않음.
      기존 사용자 STEP·SQLite·기존 계산 기록·ML 가중치 변경 없이 알려진 GeoField 버전만 업그레이드.
      실패 시 설치 대상 코드 백업/롤백. Windows 백신이 경고하면 예외 처리하지 말고 탐지 이름/경로 확인.


[포트 8600 자동 처리 통합 개선]
- 별도의 CMD나 PowerShell 명령 입력은 필요하지 않습니다.
- 시작 CMD에서 8600 점유를 감지하면 /api/status 응답, 실제 TCP 소유 PID,
  Python 실행 명령의 설치 경로 및 하위 프로세스 상태를 확인합니다.
- GeoField 소유가 확실하고 하위 실행 프로세스가 없는 경우에만 기존 서버 PID를 종료하고
  포트가 실제 비워진 후 설치합니다. 다른 프로그램/하위 작업은 강제 종료하지 않습니다.
- 서버 상태가 확인되지 않거나 권한 부족이면 안전하게 설치를 중단하고 로그를 남깁니다.
- 기존 진행 작업은 업데이트 전 저장해 두십시오. Windows Stop-Process는 이전
  백엔드를 정상 종료하는 API가 아니므로 진행 중인 미저장 작업 보존을 보증할 수 없습니다.
- 메시/FEA 계산 중에는 이 설치를 실행하지 마십시오.
- 기존 CAD/FEA/ML 파일, SQLite 기록, 솔버 데이터는 삭제하지 않습니다.
