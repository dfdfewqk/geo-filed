GeoField R12.13 최종 검증 후보 - 포트 8600 자동 복구 개선

원인: 이전 실행기는 기존 GeoField가 포트 8600에서 동작해도 120초간 대기할 뿐,
점유 서버를 식별/정리하지 못하여 코드 설치 자체를 시작하지 못함.

개선: 실행기에서 서버 응답 + Windows TCP PID + CIM 실제 프로세스 명령 경로 확인.
이전 설치 환경의 GeoField Python 백엔드임이 확인되고 직접 하위 프로세스가 없는 경우에만
해당 PID에 Stop-Process (without -Force)를 시도. PID/시작시각/명령 재확인 후 처리.
포트 해제 확인 후에만 기존 해시 검증 및 백업/롤백형 설치를 수행.

안전: 알 수 없는 앱/작업 프로세스/권한 오류/변경된 PID는 종료하지 않고 설치 중단.
기존 STEP, INP, FRD, STA, SQLite, ML 가중치와 계산식/3D 코드는 변경하지 않음.
주의: 이미 실행 중인 FEA 또는 미저장 작업이 있으면 먼저 저장하고 작업을 마친 후 설치.

테스트: Linux에서 Python 회귀/윈도우 프로세스 식별 모의 시험 통과.
실제 Windows PowerShell 프로세스 종료 및 포트 해제는 아직 실기 확인 전.
