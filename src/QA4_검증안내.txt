GeoField R12.13 QA4 — 실제 FRD ↔ 3D 응력 색상 근거 확인

기준: 기존 QA3 통합 개발본 (R12.13 기반). 원래 프로그램의 CAD·FEA·ML 소스와 사용자 자료를 유지.
변경된 배포 소스는 payload/frontend/cad.js 단 한 파일이며 나머지 12개 배포 파일은 QA3와 바이트 단위 동일.

변경사항:
- 새 FEA, 원본 검증 후 이전 결과 연결, 기록 복원 3경로에서 동일 계산의 전체 FRD 응력/변위 최대값과 표면 데이터 최대값을 교차 검사함.
- 표면 응력/변위가 전체 계산 최댓값을 유의하게 초과하면 3D 표시를 거절하며 다른 값으로 덮어쓰지 않음.
- 표면 최댓값이 내부 절점 전체 최댓값보다 작을 때 화면에 두 값의 차이를 안내함.
- MPa 비교 색상 설정·실제 응력/변위 원본·해석 경계 조건·ML 가중치 변경 없음.

독립 실제 파일 검사 (기존 3kg L_bracket.step, 한 메시):
- 저장된 INP 재파싱: 2,798 노드, C3D4 사면체 8,611개, 하중 -Z 29.41995 N.
- 실제 FRD 재파싱 대조: 전체 최대 절점 von Mises 9.183541168438241 MPa, 최대 변위 0.013145435888718181 mm.
- 전체 FRD 수치와 실제 3D 표면 필드의 최대 응력·변위 일치.
- Mean-ratio 메시 형상 품질: 최소 0.05385865, 품질 0.20 미만 2/8611개.
- 최대 응력 INP 절점 2179번, 그 절점에 인접한 사면체 8개 중 품질 0.20 미만 0개; 최저 0.74132369.
- 위 메시 품질은 형상 진단이며 응력 수렴/구조 안전 판정이 아님.

범위 제한:
- 3kg 보관된 실제 데이터만 독립 검증. 사용자 Windows에서 새로 계산한 10kg 기록의 원본은 아직 확보하지 못함.
- Windows GUI 최종 수동 검증 및 동일 물리 조건 3단계 메시 실제 계산은 아직 수행하지 않음.
- 개발 보관본: 지금 Windows 업데이트하지 않아도 됨. 최종 통합 검증 시 QA4를 포함해 시험 권장.
