# GeoField browser preview

This `gh-pages` branch contains **only a static, nonfunctional UI preview** of GeoField's CAD / FEA / AI / history workflow. No backend, STEP parsing, ML inference, real solver results, or local SQLite access is provided. It contains no user files, tokens, or engineering data.

To make the preview publicly accessible, set repository **Settings → Pages → Deploy from a branch → gh-pages / (root)**. Expected public URL once GitHub Pages is enabled: `https://dfdfewqk.github.io/geo-filed/`.

For actual Windows engineering analysis use the verified candidate from Actions. The original integration code remains on its own branch.
