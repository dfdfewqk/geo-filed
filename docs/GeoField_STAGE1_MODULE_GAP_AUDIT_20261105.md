# GeoField 1번 — CAD·FEA·ML·AI 연결 완성도 점검 (2026-11-05)

대상 브랜치: `work/geofield-step1-cross-module-provenance-20261105` (이전 1~7단계의 연속). 사용자 Windows 실사용/원본 `L_bracket.step` 최종 검증은 **아직 실행하지 않음**.

## 1. 현재 코드 연결 흐름과 근거 한계

| 구간 | 현재 코드 연결 | 코드 점검 결론 / 별도 검증 |
|---|---|---|
| STEP/CAD | `/api/cad/import`, 현재 CAD SHA+3D 메시 대응 | 입력 변경 후 이전 표시와 후속 응답 무효화. 실제 사용자 모델의 최종 화면은 마지막 Windows 검수에서만 확인 |
| ML | BrepMFR `/api/ml/latest/<job>`, R12 `/api/ml/r12/latest/<job>`, 자동 관측 | 모델 추론 상태·CAD 작업 ID·SHA 일치를 확인. *추론 완료 ≠ 독립 정확도 확인* |
| 기본 FEA | `/api/fea/run/<job>` → `/api/fea/status/<run>` → `/api/results/summary/<job>` | 새로운 계산 ID, 실제 CAD SHA와 signed case SHA를 하나로 묶음. **같은 STEP의 과거 실행 ID를 새 계산 근거로 재사용할 수 있는 틈 수정** |

| 3D | 현재 run-bound FRD 표면 응력/변위·좌표 | 표면 피크 확인은 홀·필렛 인과성/내부 최대 위치 보증 아님 |
| 로컬 AI | `/api/agent/evidence/<job>`(외부 유료 API 플래그 없음) | 결과 탭 진입 시 1회·ML/R12 terminal 근거가 뒤늦게 들어오면 동일 CAD에서 *로컬* 설명만 갱신. 단독 외부 유료 AI는 명시적 동의만 |
| 통합 HTML | 원본 INP/STA/FRD 재검증 후 현재 실행·메시 보고서 확인 | 추가 메시 검증 중 미리보기·저장 차단, 종료 후 recheck. 자동 보고서 생성은 외부 유료 호출 OFF |
| SQLite | 현재 실행 스냅샷 ID는 서버에서 직접 검증 후 읽기 전용 A/B 비교 | 기존 기록 삭제/덮어쓰기 없음. 같은 STEP의 동일/다른 솔버 실행 구분. 다른 형상 효과 단정 금지 |

## 2. 이번에 발견한 실제 연결 취약점과 수정

1. **같은 STEP의 이전 FEA 검증 결과가 새 FEA 완료 조건에 잘못 쓰일 수 있음:** CAD SHA만으로는 같은 STEP을 재실행한 과거/현재 solver를 구분하지 못함. `gfReportSelectionCurrent`에 현재 활성 실행 ID 일치 조건을 추가했고, 원클릭 후속 단계/재조회 게이트를 `(CAD job, SHA, signed case SHA, verified run ID)`의 정확한 조합으로 통일함. 기존 검증 기록은 변경하지 않음.
2. **자동 ML/R12가 결과 탭의 첫 로컬 AI 호출 이후 완료되면 AI 설명이 오래된 상태로 남음:** 실제 연구 작업의 완료·실패·대체 상태가 현재 CAD/작업 ID에 속할 때 로컬 AI의 근거 버전을 증가시키고 결과 탭에서 재조회함. 기존 로컬 AI 요청이 진행 중이면 완료 후 한 번 더 갱신. 유료 API 요청/동의는 변경하지 않음.
3. 위 수정으로 달라진 독립 단위 테스트의 모의 상태에 최신 실행 게이트·연구 갱신 함수 연결. 종전 fail-closed 검사/사용자 자료 보존 검사 삭제하지 않음.

## 3. 별도 다음 단계에서 해결할 분석 기능 (이번 구현으로 완료라고 주장하지 않음)

- **형상별 응력 집중 인과 근거:** FRD 피크 좌표가 특정 홀 또는 필렛의 물리적 원인임을 주장하려면 정확한 CAD 면 좌표 대응과 국부 메시/반력 검토가 필요함.
- **메시 수렴:** 기존 3개 메시 민감도 자료로 추세·5% 진단 가능하지만, 사전 허용오차·독립적인 해상도 및 특이점 검사가 없으면 증명/인증이라고 표시하지 않음.
- **안전율·재료:** 부하/경계의 실제성, 물성/항복강도/허용응력, 안전 기준이 독립 확보되지 않으면 판정 보류.
- **ML 모델 성능:** 학습 데이터와 분리된 독립 테스트셋에 의한 재현 가능한 성능 지표가 없으면 추론 완료만 표시.
- **Windows 검수:** 최종 코드 정리·자동 검사 이후 `docs/GeoField_ONE_PASS_WINDOWS_ACCEPTANCE_20261105.md`에 따라 **한 번** 실행, 중간 실사용 반복 테스트 요구하지 않음.

원본 STEP, 기존 SQLite, 모델/가중치, 보고서/설치 경로, `main`은 변경하지 않음. 자동검사와 사용자 Windows 실사용은 구분해서 보고한다.
