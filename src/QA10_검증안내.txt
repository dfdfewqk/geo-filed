GeoField R12.13 QA10 — 실제 메시 3회 계산 중 상태 조회 안정화

기준: QA9 업데이트형 패키지. QA9까지의 CAD/FEA/ML 계산 코드는 그대로 유지합니다.

[수정 파일]
- payload/frontend/cad.js: 메시 3단계 계산 중 HTTP 상태조회 재시도, 종료 여부 확인 전 중단 버튼 유지
- manifest.json, verify_package.py: 새 프런트엔드 SHA-256 및 이전 QA9 호환성 등록
- tests: 프런트엔드 네트워크 오류 모의 3종 및 QA9→QA10 설치·재실행·롤백 검사

[정확한 동작]
- 일시적인 상태 API 오류 최대 4번까지 2초 간격으로 재시도합니다.
- 5회 연속 오류 시 사용자에게 서버의 실제 CalculiX 작업이 아직 진행 중일 수 있음을 알립니다.
- 서버가 complete/cancelled/failed를 확인해 주기 전에는 기존 중단 버튼을 비활성화하지 않습니다.
- 신규 결과값을 생성하거나 이미 계산한 결과를 바꾸지 않습니다.

[중요]
- 상태 조회 실패 ≠ 계산 실패/중단. 동일 계산을 바로 중복 시작하지 마세요.
- 테스트는 네트워크 응답을 모의한 UI 자동 검사이며 실제 Windows/CalculiX 3회 계산은 검증하지 않았습니다.
- 현재 개발 컨테이너에는 Gmsh·CalculiX 실행 환경이 없어 3회 신규 계산 미실시입니다.
- 실제 Windows 확인은 여러 개선을 통합한 마지막 검증 단계에서 진행합니다.
- 기존 설치 런타임에 적용하는 패키지이며 단독 신규 설치본이 아닙니다.
- STEP, SQLite, INP, STA, FRD, ML 가중치 데이터는 변경하지 않습니다.
