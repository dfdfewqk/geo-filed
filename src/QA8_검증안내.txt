GeoField R12.13 QA8 — CAD·FEA 직접 조회 API의 원본 교차 검증
기준: QA7 누적 수정본. 이것은 이미 설치된 GeoField 런타임(8a9ac53a821a0eb5)을 위한 업데이트이며 단독 설치 프로그램이 아닙니다.

1. GET /api/fea/status/<run_id> 의 완료 응답도 INP/STA/FRD 원본과 계산 조건을 다시 대조합니다.
   원본이 없거나 조건/수치 검증이 실패하면 complete 수치를 제공하지 않고 failed 상태를 응답합니다.
   실행 중/실패 작업에서 기존 result 필드가 노출되지 않도록 유지합니다.
2. GET /api/model/<cad_id> 는 현재 활성 CAD 작업 ID 및 STEP SHA-256과 일치하는 JSON 메시만 반환합니다.
   예전 CAD ID, 다르게 해시된 모델 파일, 심볼릭 링크 파일은 표시 거절됩니다.
3. FEA 계산식·3D 렌더링 로직·ML 가중치·기존 STEP/FRD/INP/STA/SQLite는 변경하지 않습니다.
4. QA7→QA8 안전 업데이트 모의 시험에서는 백엔드 코드 1개만 교체되며, 재실행/롤백/사용자 데이터 보존이 확인됩니다.
5. Python 회귀 테스트 61개 통과; 배포 파일 검증/JS 문법 검사 통과. 실제 Windows/WebGL/Gmsh/CalculiX 종단 간 및 실제 3단계 메시 수렴은 여전히 미검증입니다.

이번 ZIP은 QA8 누적 개발 보관본입니다. 최종 Windows 검증 시 단일 설치 절차로 사용하며, 중간 단계별 설치는 요구하지 않습니다.
